# 회사 터뜨리기 💥

> 오늘도 고생한 당신에게, 회사 하나 터뜨릴 권리를 드립니다.

**생일 선물로 시작하는, 45초짜리 직장인 스트레스 해소 웹게임.**
가상의 사무실에서 야근·회의·수정 요청을 부수고, 마지막에는 거대한 퇴사빔으로 건물을 종이 조각처럼 날린다.

이 저장소는 기획 단계다. 현재 공개 파일은 이 문서 하나이며, 게임 구현과 서비스 배포는 다음 단계다.

## 1. 기획의 중심

| 항목 | 결정 |
| --- | --- |
| 이름 | 회사 터뜨리기 |
| 한 줄 소개 | 출근은 했지만, 건물은 못 지켰습니다. |
| 장르 | 탭 액션 + 짧은 파괴 연출 + 결과 카드 |
| 대상 | 친구에게 웃긴 생일 선물을 보내고 싶은 사람, 잠깐 스트레스를 풀고 싶은 직장인 |
| 플랫폼 | 모바일 웹 우선, PC 마우스·키보드 지원 |
| 플레이 길이 | 준비 약 5초 → 게임 45초 → 피날레 약 4초 → 결과 |
| 핵심 감정 | 귀찮음 → 타격감 → 과장된 해방감 → 친구에게 공유하고 싶은 웃음 |
| 첫 버전 운영 | 로그인·결제·서버 저장 없이 무료 플레이 |

**성공 기준은 정교한 물리 시뮬레이션보다, 첫 탭부터 재미있고 마지막 폭발을 다시 보고 싶은가다.**

모든 장소와 회사는 허구다. 화면의 파괴 대상은 사무용품과 건물이며, 사람 캐릭터는 등장하지 않는다. 로켓 펀치와 광선 등 만화적 연출을 사용한다.

## 2. 첫 방문 경험

1. 선물 상자와 함께 “생일 선물로 회사를 준비했어요.”가 나타난다.
2. 상자가 열리면 작은 사무실 건물이 튀어나온다. 간판은 기본값 **주식회사 내일부터**.
3. “마음껏 터뜨리세요.” 아래 **[선물 뜯고 시작]**을 누른다.
4. 첫 표적 ‘월요일 회의’를 탭하며 바로 게임을 배운다. 첫 타격 후 45초 타이머가 시작된다.
5. 서류 더미, 프린터, 회의실을 부술수록 분노 게이지와 점수가 오른다.
6. 게이지가 차면 **[퇴사빔 발사]** 버튼이 켜진다. 누르거나 시간이 끝나면 피날레로 넘어간다.
7. 생일 축하 폭죽과 결과 카드가 나타난다. **[한 번 더]**, **[카드 저장]**, **[링크 공유]**를 제공한다.

일반 모드에서는 첫 문구를 “오늘 받은 스트레스, 여기 두고 가세요.”로 바꾼다. 생일 모드는 기본 선택하되 준비 화면에서 바꿀 수 있다.

## 3. 게임 규칙

### 기본 조작과 표적

- 플레이 영역에는 표적 6개를 배치한다. 부서진 자리에는 0.35초 뒤 다음 표적이 나타난다.
- 표적은 같은 순환 목록에서 등장한다. 첫 6개 배치는 고정하여 조작을 익히기 쉽게 한다.
- 한 번의 탭 또는 클릭은 피해 1이다. 누르고 있기나 드래그로 자동 공격하지 않는다.
- 명중 즉시 눌림, 균열, 짧은 효과음이 나오고, 파괴 시 종이·픽셀 조각과 점수가 튀어나온다.
- 빈 공간을 눌러도 벌점이 없다. 파괴 직후 재등장 대기 중인 슬롯을 눌러도 입력을 무시한다.

| 표적 | 필요한 타격 | 파괴 기본 점수 | 파괴 문구 예시 |
| --- | ---: | ---: | --- |
| 회의 자료 | 1 | 100 | 이 회의는 메일로 끝났습니다. |
| 수정 요청 프린터 | 2 | 250 | 최종_진짜최종_폭발.pdf |
| 야근 책상 | 3 | 450 | 오늘은 정시 퇴근입니다. |

파괴 문구는 짧게 한 줄만 표시하고 다음 표적을 가리지 않는다. 표적마다 HP를 작은 칸으로 표시한다.

### 콤보·분노·피날레

- **콤보:** 마지막 유효 명중에서 1.2초 안에 다시 명중하면 이어진다. 1.2초를 초과하면 다음 명중부터 1로 다시 시작한다.
- **배율:** 현재 콤보 1–4는 ×1, 5–9는 ×1.5, 10 이상은 ×2다. 파괴를 일으킨 명중까지 포함해 배율을 계산한다.
- **분노:** 유효 명중마다 +2, 표적 파괴마다 추가 +4를 얻는다. 0~100으로 제한하고 감소하지 않는다.
- **필살기:** 분노 100에서 퇴사빔 버튼이 활성화된다. 즉시 발사할 수도, 남은 시간 동안 점수를 더 모을 수도 있다.
- **시간 종료:** 분노 100이면 자동으로 퇴사빔을 발사한다. 100 미만이면 쌓인 분노에 비례한 작은 폭발로 마무리한다. 모든 플레이는 결과 화면에 도달한다.
- **피날레 길이:** 게이지와 관계없이 약 4초. 100에서는 건물 전체가 종이 조각으로 변하고 케이크가 남는다.
- **점수:** 각 표적의 `기본 점수 × 파괴 시 콤보 배율` 합계에 `피날레 진입 시 분노 × 20`을 더한다. 소수는 발생하지 않는다.
- **계산 예:** 회의 자료 2개와 프린터 1개를 총 4번의 명중으로 파괴한 뒤 공격하지 않으면, 모두 ×1이고 분노는 `4 × 2 + 3 × 4 = 20`이다. 시간 종료 후 총점은 `200 + 250 + 400 = 850점`이다.

피날레에 들어가는 순간 공격 입력과 점수 계산을 잠근다. 시간 종료와 버튼 클릭이 동시에 발생해도 한 번만 종료한다.

### 결과와 재도전

결과에는 총점, 부순 표적 수, 최대 콤보, 최고 기록 갱신 여부를 표시한다. 등급은 총점으로 결정한다.

| 총점 | 칭호 |
| --- | --- |
| 0~2,999 | 오늘도 참은 사람 |
| 3,000~5,999 | 회의실의 재앙 |
| 6,000~9,999 | 정시 퇴근 수호자 |
| 10,000 이상 | 전설의 퇴사자 |

등급 경계와 분노 충전량은 초기 가설이다. 실제 플레이에서 보통 속도의 첫 시도도 45초 안에 퇴사빔에 도달하는지 확인하고 조정한다.

## 4. 화면 구성과 문구

| 화면 | 구성 | 대표 문구 / 행동 |
| --- | --- | --- |
| 준비 | 선물 상자, 제목, 생일 모드, 선택 입력, 시작 버튼 | “생일 축하해. 오늘 회사는 내가 쏜다.” |
| 플레이 | 상단 남은 시간·점수, 중앙 사무실 표적 6개, 하단 분노·퇴사빔 | “회의 하나쯤은 없어져도 괜찮잖아.” |
| 피날레 | 빔 충전 → 발사 → 건물 붕괴 → 케이크 | “업무 종료. 생일 시작.” |
| 결과 | 칭호, 점수, 통계, 저장·공유·재시작 | “건물은 사라졌고, 당신의 생일은 남았습니다.” |

준비 화면에서 **받는 사람 별명(최대 12자)**과 **가상 회사 간판(최대 16자)**을 선택 입력한다. 빈 값은 ‘오늘의 주인공’과 ‘주식회사 내일부터’로 대체한다. 입력값은 HTML로 해석하지 않고 텍스트로만 출력한다.

생일 모드를 켜면 케이크와 축하 문구가, 끄면 퇴근 도장과 “오늘도 수고했어요.”가 나온다. 입력 때문에 바로 시작하는 흐름이 막히지 않도록 선택 입력은 접힌 상태로 둔다.

## 5. 비주얼·사운드 방향

- **스타일:** 장난감 같은 2.5D 사무실. 굵은 외곽선, 큼직한 간판, 단순한 물체 실루엣으로 작은 화면에서도 표적을 구분한다.
- **색:** 짙은 남색 `#171827` 배경, 크림색 `#FFF4DB` 사무실, 보라색 `#7048FF` 주요 버튼, 노랑 `#FFD84D` 콤보, 코랄 `#FF665A` 타격 강조.
- **타격감:** 명중 때 약 80ms 눌림과 반동, 파괴 때 조각 확산, 큰 폭발 때만 짧은 화면 흔들림. 텍스트가 읽히는 시간은 확보한다.
- **사운드:** 종이 찢김, 프린터 오류음 패러디, 짧은 빔 충전음, 축하 팡파르. 첫 사용자 조작 후 오디오를 활성화한다.
- **접근성:** 음소거, 움직임 줄이기 설정, 색 외의 HP 표시를 제공한다. 표적과 필살기는 키보드로도 조작하며 탭 영역은 최소 44px로 한다.
- **소재 제작:** 초기 사무실과 파괴 조각은 직접 만든 SVG/Canvas 그래픽, 효과음은 직접 생성하거나 사용 권한이 확인된 소재로 구성한다.

## 6. 공유 경험

**결과 카드 예시**

> 오늘의 주인공님, 생일 축하합니다! 🎂  
> 오늘의 업적: 주식회사 내일부터 철거 완료  
> 8,450점 · 정시 퇴근 수호자  
> 회사 터뜨리기

- **카드 저장:** 현재 별명·가상 간판·점수·칭호를 담은 PNG를 기기에서 생성한다. 이미지 생성 실패 시 결과 텍스트 복사로 이어진다.
- **링크 공유:** Web Share API가 가능하면 공유 창을 열고, 미지원이면 링크를 복사한다. 복사도 실패하면 직접 선택 가능한 링크를 보여준다.
- **개인화 범위:** 첫 버전은 기본 게임 주소만 공유한다. 별명과 간판은 URL에 넣지 않으며, 결과 카드에만 포함한다.
- 공유 취소는 오류 팝업 없이 결과 화면으로 돌아온다. 업로드나 공개 피드는 만들지 않는다.

## 7. MVP 범위

### 첫 출시에서 완성할 것

- 준비 → 첫 타격 → 45초 플레이 → 피날레 → 결과 → 재시작 전체 흐름
- 표적 3종, 슬롯 6개, 체력·콤보·분노·점수 규칙
- 퇴사빔과 분노가 덜 찼을 때의 피날레
- 생일/일반 모드, 별명·가상 간판 선택 입력
- 결과 PNG 저장, 게임 링크 공유, 브라우저 내 최고 점수 저장
- 음소거·움직임 줄이기·일시정지, 모바일 및 PC 입력
- 기본 소셜 미리보기 이미지와 한국어 메타데이터

### 반응을 본 뒤 추가할 것

- 사직서 수리검, 월급 메테오 등 필살기 스킨
- 회의 지옥·마감 전날 등 사무실 테마
- 친구에게 보내는 개인화 생일 링크
- 일일 챌린지와 기록 대결

첫 버전에는 계정, 온라인 랭킹, 채팅, 결제, 실제 지도·회사 검색, 사진 업로드, 사실적인 건물 물리를 넣지 않는다. 타격감과 재도전 흐름에 개발 시간을 집중한다.

## 8. 구현 설계

아래는 구현 시 사용할 제안이며, 아직 설치하거나 검증한 기술 구성은 아니다.

| 영역 | 제안 | 이유 |
| --- | --- | --- |
| 앱 | Vite + TypeScript | 서버 데이터가 없는 작은 게임을 정적 파일로 빌드 |
| 화면 | HTML/CSS UI + Canvas 2D 게임 장면 | 버튼·입력 접근성과 파괴 효과를 분리하여 관리 |
| 접근 가능한 조작 | Canvas 표적 위치에 대응하는 HTML 버튼 6개 | Tab 이동과 Enter/Space 입력에도 동일한 공격 함수 호출 |
| 렌더링 | requestAnimationFrame, 활성 플레이 시간 기준 타이머 | 화면 갱신과 남은 시간을 일관되게 처리 |
| 효과음 | Web Audio 또는 로컬 오디오 파일 | 첫 조작 이후 재생, 음소거 일괄 적용 |
| 결과 카드 | 별도의 Canvas에 텍스트와 그래픽 합성 | 외부 이미지 의존 없이 PNG 생성 |
| 저장 | localStorage | 최고 기록과 음소거·동작 설정만 저장 |
| 배포 | Coolify에서 정적 빌드 제공 | 기존 운영 환경을 활용하는 후속 배포 계획 |

게임 상태는 `ready → playing ↔ paused → finale → result`로 관리한다. 재시작은 `result → ready`로 돌아가며, 표적·점수·게이지·이전 이벤트 핸들러를 초기화한다.

- 타이머는 첫 유효 명중부터 시작한다. 애니메이션 프레임 수로 시간을 세지 않는다.
- 탭 전환·화면 잠금 감지 시 일시정지하며, 복귀 후 **[계속하기]**를 눌러야 다시 진행한다. 피날레 중 숨겨진 경우도 연출 시간을 보존한다.
- 저장소 접근이 차단되어도 메모리 상태로 플레이하고 결과 화면까지 진행한다.
- 별명과 간판은 페이지 세션 메모리에만 보관한다. 분석·서버 전송은 첫 버전에 없다.
- 성능 목표는 일반적인 모바일 화면에서 부드러운 60fps이며, 느린 기기에서는 파티클 개수를 낮춘다. 이는 테스트로 확인할 목표다.
- Coolify 연동은 구현 후 진행한다. 빌드 명령은 `npm ci && npm run build`, 산출물은 `dist`를 기준으로 계획하고 실제 실행 구성을 배포 전에 검증한다.
- 운영 키와 인증 정보는 소스·문서·이미지·Git 기록에 넣지 않는다. 필요한 운영 설정은 배포 환경에서 관리한다.

## 9. 개발 순서와 완료 조건

| 단계 | 작업 | 완료 조건 |
| --- | --- | --- |
| 1. 플레이 뼈대 | 화면 전환, 표적, 타이머, 점수, 재시작 | 임시 그래픽으로 한 판을 끝내고 다시 시작할 수 있다. |
| 2. 손맛 | 콤보, 분노, 피날레, 파티클, 효과음 | 첫 탭 피드백이 즉시 보이고 퇴사빔까지 연결된다. |
| 3. 선물 포장 | 생일 모드, 입력, 결과 카드, 공유 | 별명이 반영된 결과 이미지를 저장할 수 있다. |
| 4. 출시 점검 | 입력·성능·접근성·오류 검증, Coolify 배포 | 모바일과 PC에서 실제 URL로 전체 흐름을 완료한다. |

배포는 실제 게임 구현과 아래 검증을 마친 뒤 진행한다. 현재 공개 저장소를 만드는 작업만으로 서비스가 배포되는 것은 아니다.

### 반드시 확인할 시나리오

1. 입력값 없이 바로 시작해 첫 타격부터 45초가 흐르고 정상 종료되는가?
2. 한 번도 공격하지 않으면 시작 전 상태를 유지하고, 첫 공격 후 방치하면 낮은 점수로 끝나는가?
3. 콤보 4→5, 9→10 경계와 1.2초 초과 초기화에서 점수가 규칙과 일치하는가?
4. 분노 100의 수동 발사·자동 발사, 분노 미달 종료가 각각 한 번만 실행되는가?
5. 파괴 중인 표적 연타, 멀티터치, 필살기 연속 클릭으로 점수가 중복되지 않는가?
6. 일시정지·탭 전환·복귀와 10회 재시작에서 타이머나 효과음이 겹치지 않는가?
7. 긴 한글·이모지·HTML 형태 입력도 화면을 깨뜨리지 않고 텍스트로 표시되는가?
8. iOS Safari·Android Chrome·데스크톱 Chrome에서 표적 터치, 카드 저장, 공유 또는 대체 동작이 가능한가?
9. 360px 너비 화면, 키보드 조작, 음소거, 움직임 줄이기에서 진행을 막는 요소가 없는가?
10. 배포 URL에서 새로고침·정적 자산 로딩이 정상이며 브라우저와 서버 로그에 관련 오류가 없는가?

점수·콤보·종료 중복 방지는 로직 테스트로 확인하고, 타격감·공유·모바일 입력은 실제 브라우저 플레이로 확인한다.

## 10. 출시 후 판단

첫 사용성 테스트에서 다음 질문을 확인한다. 수치는 성과가 아니라 초기 검증 목표다.

- 별도 설명 없이 5초 안에 첫 공격을 하는가?
- 첫 플레이에서 분노 100에 도달하고 필살기의 존재를 알아차리는가?
- 45초가 길게 느껴지지 않으며, 다시 하기 버튼을 자연스럽게 찾는가?
- 결과 카드가 생일 축하 선물로 보이며 문구가 웃긴가?
- 파괴 반응이 약하다면 콘텐츠를 늘리기 전에 타격 애니메이션과 사운드를 먼저 개선한다.

**개발 우선순위: 첫 탭의 손맛 → 퇴사빔 피날레 → 생일 결과 카드 → 추가 콘텐츠.**
